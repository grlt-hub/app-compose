## Cursor

1. Open chat and type `@docs`
2. Click **Add new doc**
3. Paste the URL and confirm:

```
https://app-compose.dev/llms.txt
```

## Claude / ChatGPT / Copilot

Paste this URL into the chat — most assistants accept URLs as context:

```
https://app-compose.dev/llms.txt
```
