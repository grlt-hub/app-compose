## Install the package

Use your preferred package manager.

<Tabs>
  <TabItem label="npm">
  
    ```bash
    npm install --save-exact @app-compose/coda

    ```

  </TabItem>
  <TabItem label="pnpm">

    ```bash
    pnpm add --save-exact @app-compose/coda

    ```

  </TabItem>
  <TabItem label="yarn">

    ```bash
    yarn add --exact @app-compose/coda

    ```

  </TabItem>
  <TabItem label="bun">

    ```bash
    bun add --exact @app-compose/coda

    ```

  </TabItem>
</Tabs>
